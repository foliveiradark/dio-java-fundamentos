## 👨‍💻 Sobre este repositório

Este repositório reúne exercícios, desafios e projetos desenvolvidos durante minha formação em Java pela Digital Innovation One (DIO).

Mais do que armazenar atividades do curso, o objetivo é registrar minha evolução técnica, aplicar boas práticas de desenvolvimento e consolidar conhecimentos que serão utilizados na construção de aplicações back-end profissionais.

Ao longo da formação, o projeto evolui desde conceitos fundamentais da linguagem até tópicos avançados como Programação Orientada a Objetos, Persistência de Dados, APIs com Spring Boot, Testes Automatizados e Inteligência Artificial aplicada ao desenvolvimento.

## 🔄 Migração Maven ↔ Gradle

Durante os estudos também foram realizados experimentos de migração entre ferramentas de build:

* Conversão de dependências entre `pom.xml` e `build.gradle`
* Comparação entre XML e DSL
* Equivalência entre scopes e configurations
* Ajuste de plugins e configurações
* Comparação entre lifecycle do Maven e tasks do Gradle

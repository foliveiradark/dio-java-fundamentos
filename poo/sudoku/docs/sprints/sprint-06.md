# 🔄 Sprint 6 — Melhorar identificação das coordenadas

## 🎯 Objetivo

Melhorar a usabilidade da interface do Sudoku, permitindo que o jogador identifique facilmente as linhas e colunas do tabuleiro durante a partida.

---

## 📦 Escopo

- US-006 — Melhorar identificação das coordenadas

---
### Critérios de aceitação

* Exibir índices de linhas;
* Exibir índices de colunas;
* Facilitar a interação do jogador.

---
## Sprint Review

### User Stories concluídas

- ✅ US-006 — Melhorar identificação das coordenadas.

---

### Melhorias realizadas
- Exibição dos índices das colunas (1–9);
- Exibição dos identificadores das linhas (A–I);
- Ajuste do alinhamento visual do tabuleiro;
- Reutilização dos métodos de impressão para manter a consistência da interface;
- Padronização da apresentação do tabuleiro.

### Débitos técnicos identificados
* Melhorar as coordenadas utilizando letras (A–I) para as linhas e números (1–9) para as colunas, 
convertendo automaticamente esses valores para os índices internos utilizados pelo domínio.
* Melhorar a aparência visual do tabuleiro utilizando caracteres Unicode para destacar melhor os
blocos 3x3, melhorar a interface e padronizar o espaçamento.
---

## Status

✅ Concluída

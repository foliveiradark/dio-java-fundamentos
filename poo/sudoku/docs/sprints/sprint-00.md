# 🔄 Sprint 0 — Planejamento e Modelagem

## 🎯 Objetivo

Estruturar o projeto antes do desenvolvimento das funcionalidades, definindo arquitetura, organização dos arquivos e principais entidades do domínio.

---

## ⚙️ Funcionalidades

Nesta sprint não houve implementação de regras do jogo.

Foram realizadas atividades de preparação do projeto.

---

## 📝 Atividades realizadas

- Criação da estrutura do repositório.
- Organização da documentação.
- Definição da arquitetura inicial.
- Definição das classes principais.
- Discussão das responsabilidades de cada classe.

---

## 🧬 Classes definidas

- Casa
- Tabuleiro
- JogoSudoku
- ConsolePrinter
- Menu

---

## 🔀 Decisões de arquitetura

- O Tabuleiro será responsável por criar suas próprias 81 casas.
- Cada classe será responsável por validar seu próprio estado.
- O projeto será desenvolvido seguindo princípios de Programação Orientada a Objetos.
- O desenvolvimento será incremental, com pequenas entregas e validações constantes.
- Definição da separação entre domínio (`model`) e interface (`ui`).

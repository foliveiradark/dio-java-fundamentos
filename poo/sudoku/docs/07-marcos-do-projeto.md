# 🚀 Marco 1 — MVP Console

### Data: 03/08/2026

Status: ✅ Concluído

---

## 🎯 Objetivo

Construir uma versão totalmente funcional do Sudoku em modo texto, contemplando as funcionalidades essenciais para que uma partida possa ser iniciada, jogada, validada e concluída.

---

## ⭐ Funcionalidades implementadas

Foram implementadas as seguintes funcionalidades:

- visualização do tabuleiro;
- carregamento de partidas;
- inserção e remoção de números;
- validação de jogadas;
- limpeza das jogadas;
- verificação do status da partida;
- encerramento automático da partida;
- tratamento de entradas inválidas;
- entrada de coordenadas no formato A1–I9;
- validação das confirmações (S/N);
- validação do Menu Principal;
- refinamento da interface visual do tabuleiro.

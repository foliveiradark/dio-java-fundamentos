---

# 🎯 Objetivo

Calcular a área de diferentes figuras geométricas utilizando uma interface comum.

As figuras implementadas são:

- Quadrado
- Retângulo
- Círculo

---

# 🧠 Conceitos praticados

- Interfaces
- Polimorfismo
- Encapsulamento
- Validação de dados
- Tratamento de exceções
- Coleções (`List`)
- Sobrescrita de métodos

---

# 📚 Aprendizados

Neste exercício foi possível consolidar o uso de interfaces sem a necessidade de utilizar herança.

O projeto reforça a importância de escolher corretamente entre interfaces e classes abstratas, evitando criar hierarquias desnecessárias e mantendo o código simples, coeso e de fácil manutenção.
